# 研究与复杂搜索通用方法

当用户需要深入研究一个问题、梳理一个话题的多方观点、或跟进某个领域的近期进展时，使用开放平台**「搜全网 + 搜知乎 + 搜知识库」三角对账法**，并路由到对应场景指南：

场景入口见 [主 Skill](../SKILL.md#研究场景)。

### 知乎好回答深挖四步法（研究与复杂搜索任务通用）

1. **先找母问题与热议切面**：调用 `<CLI> question recommend --query "核心主题" --count 10`，定位知乎社区讨论最集中的高关注母问题；热点事件配合 `<CLI> hot --limit 30`。
2. **三路短词检索 + 拉回答列表**：避免五六个关键词生硬拼接。用 `<CLI> search zhihu --query "..." --count 10` 分三路检索（① 母问题与核心对比；② `主题 后悔/踩坑/缺点/翻车`；③ `主题 原理/成本/架构/实测`），并对核心母问题调用 `<CLI> question answers --question-url "..." --limit 20` 横向浏览多方观点交锋。
3. **黄金选材三原则**：结合 `VoteUpCount`、`AuthorityLevel` 与千字 `ContentText`，剔除「目录式带货导购文」与「0–1 赞搬运水帖」；优先选用**有真实样本与代价的亲历、刺破账面宣传的机制解释、能改变结论的边界反例**。使用宿主提供的网页读取工具补读关键来源；无法访问时保留摘要，并明确未读取全文。
4. **全网一手事实与知识库对账**：用 `<CLI> search global`（近期动态加 `--search-db realtime`，权威站点加 `--filter 'host=="..."'`）核实官方参数、公告与论文；用户提供本地文档或指定知识库时，配合 `<CLI> knowledge search / upload` 对齐具体约束。引用答主时直接亮出其身份背景、赞同数与原话金句，把适用条件写成清晰的判断。
